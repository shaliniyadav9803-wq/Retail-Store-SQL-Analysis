# Retail Store SQL Analysis

## 📌 Project Overview

This project focuses on analyzing a retail store database using MySQL and SQL queries.

The database contains information about customers, products, orders, order items, payments, and product reviews. The project demonstrates how SQL can be used to explore data, connect related tables, and generate meaningful insights from a retail database.

## 🗂️ Database Structure

The project contains six main tables:

- **Customers** – Customer information
- **Products** – Product details, categories, prices, and stock
- **Orders** – Order information and order status
- **Order Items** – Products included in each order
- **Payments** – Payment details for orders
- **Product Reviews** – Customer reviews and product ratings

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench

- SELECT

- JOINs

- Foreign Keys

## 📊 Analysis Areas

The SQL analysis covers areas such as:

- Customer and product data exploration
- Order analysis
- Product and category analysis
- Payment analysis
- Product review and rating analysis
- Aggregation and filtering
- Combining data from multiple related tables

The objective of this project is to practice SQL and demonstrate the ability to work with a relational retail database using queries, aggregations, joins, filtering, and subqueries.
